# AI PR Review 助手开发计划

## 版本规划

| 版本 | 定位 | 状态 |
|------|------|------|
| V1 | 原始 MVP — 跑通 PR Review 主链路 | ✅ 已完成 |
| V2 | 工程增强 — 缓存、限流、监控、固定评分 | ⚠️ 部分完成 |
| V3 | Skill 化 — 可插拔专项评审 | 未开始 |
| V4 | Agent 化 — Spring AI 智能编排 | 未开始 |
| V5 | 评测闭环 — 质量反馈与微调数据 | 未开始 |

## 评审耗时优化

| 层级 | 内容 | 状态 |
|------|------|------|
| **P0** | 创建任务立即返回 + 轮询进度 + 缓存复用 + Diff 过滤 + Patch 截断 | ✅ 已完成 |
| **P1** | 文件级并发 + 单文件超时 + 智能重试 | ✅ 已完成 |
| **P1** | 部分结果可用 + 数据库耗时字段 | 未开始 |
| **P2** | SSE 推送 + 消息队列 + 多模型分层 + 熔断保护 | 未开始 |

## P0 已实现功能

1. **创建任务立即返回** — POST /api/review-tasks 不等待 AI 完成，毫秒级响应
2. **报告页轮询** — ReviewReportView 每 2s 拉取进度，SUCCESS 后自动加载
3. **数据库缓存复用** — 同 PR 同 commit 同模型同 Prompt 版本命中后直接返回历史报告
4. **Diff 预处理** — DiffPreprocessor 在保存文件前过滤 lock 文件/二进制/空 patch
5. **Patch 截断** — 单文件 >12000 字符在 PromptRenderer 截断
6. **进度追踪** — ReviewTaskDetailVO 返回 progressPercent/currentStep/文件计数
7. **SCORING 状态** — 风险评分阶段独立展示

## P1 已实现功能

1. **文件级并发评审** — CompletableFuture + fileReviewExecutor，默认 3 并发
2. **单文件超时控制** — 每个文件 60s 硬超时，超时标记失败不中断任务
3. **智能重试** — 仅对 5xx/IOException 重试 1 次，4xx 不重试避免浪费 Token
