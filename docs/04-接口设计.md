# 接口设计

## 统一返回格式

成功：

```json
{
  "code": 0,
  "message": "success",
  "data": {}
}
```

失败：

```json
{
  "code": 40001,
  "message": "PR 链接格式错误，请输入 GitHub Pull Request 地址",
  "data": null
}
```

## 健康检查

```http
GET /api/health
```

## GitHub PR 预览

```http
POST /api/github/preview
Content-Type: application/json
```

请求：

```json
{
  "prUrl": "https://github.com/example/demo/pull/12"
}
```

响应：

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "owner": "example",
    "repo": "demo",
    "pullNumber": 12,
    "title": "待接入 GitHub API 的 PR 预览",
    "author": "unknown",
    "sourceBranch": "head",
    "targetBranch": "base",
    "state": "OPEN",
    "additions": 0,
    "deletions": 0,
    "changedFiles": 0,
    "files": []
  }
}
```

## 创建 Review 任务

```http
POST /api/review-tasks
Content-Type: application/json
```

请求：

```json
{
  "prUrl": "https://github.com/example/demo/pull/12"
}
```

响应：

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "taskId": 1,
    "status": "PENDING"
  }
}
```

## 查询 Review 报告

```http
GET /api/review-tasks/{taskId}/report
```

响应字段包含：

```text
taskId
summary
riskScore
riskLevel
mainChanges
riskItems
testSuggestions
finalReview
```
