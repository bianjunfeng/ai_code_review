# 接口设计

## 统一返回格式

成功：

```json
{
  "code": 0,
  "message": "success",
  "data": {}
}
```

失败：

```json
{
  "code": 40001,
  "message": "PR 链接格式错误，请输入 GitHub Pull Request 地址",
  "data": null
}
```

## 健康检查

```http
GET /api/health
```

## GitHub PR 预览

```http
POST /api/github/preview
Content-Type: application/json
```

请求：

```json
{
  "prUrl": "https://github.com/example/demo/pull/12"
}
```

响应：

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "owner": "example",
    "repo": "demo",
    "pullNumber": 12,
    "title": "feat: add login api",
    "body": "Add login endpoint and related tests.",
    "author": "octocat",
    "sourceBranch": "feature/login",
    "targetBranch": "main",
    "state": "open",
    "additions": 20,
    "deletions": 5,
    "changedFiles": 1,
    "files": [
      {
        "filename": "src/main/java/UserService.java",
        "status": "modified",
        "additions": 20,
        "deletions": 5,
        "changes": 25,
        "patch": "@@ -1,1 +1,2 @@"
      }
    ]
  }
}
```

错误码：

| code | message |
| --- | --- |
| 40001 | PR 链接格式错误，请输入 GitHub Pull Request 地址 |
| 40101 | GitHub Token 无效，请检查 GITHUB_TOKEN |
| 40301 | GitHub 仓库无权限或 API 限流，请检查 Token 或稍后重试 |
| 40401 | GitHub 仓库或 PR 不存在 |
| 42201 | PR 编号无效 |
| 50001 | GitHub API 调用失败，请稍后重试 |
| 50002 | GitHub 服务异常，请稍后重试 |

## 创建 Review 任务

```http
POST /api/review-tasks
Content-Type: application/json
```

请求：

```json
{
  "prUrl": "https://github.com/example/demo/pull/12"
}
```

响应：

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "taskId": 1,
    "status": "REVIEWING"
  }
}
```

说明：

```text
当前 MVP 后端在创建任务时同步完成 PR 信息和 changed files 获取，因此创建成功后状态会进入 REVIEWING，表示 PR 获取闭环完成，等待 AI Review 接入。
后续如果改成异步任务，可先返回 PENDING，再通过任务详情接口查询状态流转。
```

## 查询 Review 建议

```http
GET /api/review-tasks/{taskId}/comments
```

响应：

```json
{
  "code": 0,
  "message": "success",
  "data": []
}
```

说明：

```text
AI Review 接入前该接口返回空数组；后续由 AiReviewService 解析模型 JSON 后写入 review_comment 数据。
```

## 查询 Review 报告

```http
GET /api/review-tasks/{taskId}/report
```

响应字段包含：

```text
taskId
status
prInfo
summary
riskScore
riskLevel
mainChanges
riskItems
files
testSuggestions
finalReview
```

当前报告由 ReviewReportService 从任务、文件、评论聚合生成；AI Review 未接入前，riskItems 和 testSuggestions 可以为空。
