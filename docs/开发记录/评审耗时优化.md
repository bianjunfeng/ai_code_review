## P1：并发加速 + 超时容错 + 智能重试（已完成）

- **分支**：`feature/pr05-concurrent-review`

- **内容**：CompletableFuture + fileReviewExecutor（默认 3 并发），CallerRunsPolicy 背压

### PR⑥ — 单文件超时控制
- **分支**：`feature/pr06-file-timeout`
- **文件**：`ReviewProperties.java`、`ReviewTaskExecutor.java`
- **内容**：每个文件 60s 硬超时 `.orTimeout()`，超时文件标记失败不中断任务
- **配置**：`review.ai.file-review-timeout-seconds=60`

### PR⑦ — 智能重试策略
- **分支**：`feature/pr07-smart-retry`
- **文件**：`RetryInterceptor.java`、`OpenAiCompatibleClient.java`
- **内容**：4xx（鉴权/参数错误）不重试，仅 5xx/IOException 重试 1 次，重试次数 3→1

## 关键技术决策

1. **CallerRunsPolicy + 队列=0**：溢出任务由提交线程执行，充当自然背压
2. **orTimeout 不真正中断 HTTP**：CompletableFuture 提前完成，OkHttp 120s 超时兜底释放线程
3. **不引入 MQ/WebSocket/熔断框架**：当前单用户低频场景不需要
4. **failedFileCount 用 ai_summary 前缀匹配**：免去新增数据库字段
